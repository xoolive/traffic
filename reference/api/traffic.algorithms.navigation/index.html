traffic.algorithms.navigation¶

ApplyBase ¶

Bases: Protocol

Classes following this protocol should implement an apply method which returns a :class:~traffic.core.Flight.

ApplyIteratorBase ¶

Bases: Protocol

Classes following this protocol should implement an apply method which returns an iterator of :class:~traffic.core.Flight.

ApplyOptionalBase ¶

Bases: Protocol

Classes following this protocol should implement an apply method which returns None or a :class:~traffic.core.Flight.
